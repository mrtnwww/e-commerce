Crear un componente de blade

```bash
php artisan make:componente AdminLayout
```

> Crea 2 archivos, \App\View\Components\AdminLayout.php y \resources\views\components\admin-layout.blade.php

Crear un componente de Livewire

```bash
php artisan make:livewire admin.subcategories.SubcategoryEdit
```

> Crea un archivo llamado SubcategoryEdit dentro de la ruta \app\LiveWire\Admin\Subcategories y un archivo llamado subcategory-edit dentro de la ruta \resources\views\livewire\admin\subcategories
